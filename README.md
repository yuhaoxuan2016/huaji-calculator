# huaji-calculator

huaji calculator

小时候练习写的程序，仅用作留存 —— 现在，它是**真·计算器**了 /滑稽

## 🛜 网页版（新）

单一文件、零依赖、打开即用：**[index.html](index.html)**
- 兔 logo + 滑稽彩蛋风格，与 rabbit 系列应用同款视觉
- 加减乘除、百分比、正负号、退格、清除
- 支持键盘操作（数字 / 运算符 / Enter / Backspace / Esc）
- 历史记录（点击回填），错误输入保留童年遗风「你是来搞笑的吧！/滑稽」
- 移动端自适应

> 也可以开 GitHub Pages，直接用 `https://yuhaoxuan2016.github.io/huaji-calculator/` 在线玩。
